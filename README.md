# Maze Escape

A dependency-free browser game using randomized depth-first search to generate a connected maze with a unique route between any two cells.

Open `index.html` in a browser. Use arrow keys or on-screen controls to reach the gold exit. Generate a fresh maze with New maze.

Run algorithm tests with Node.js 22: `node --test maze.test.js`.

GitHub Actions runs the tests on pushes and pull requests. Browser interaction and hosted test results remain unverified.
